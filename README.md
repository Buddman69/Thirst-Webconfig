# Thirst Config

The configuration page for Thirst controllers. Open it in Chrome or Edge, plug the controller in
by USB and press **Connect controller**.

**https://buddman69.github.io/Thirst-Webconfig/**

- Talks to the controller directly through the browser (WebHID). Nothing to install, and nothing
  you set leaves your computer: every setting is saved on the controller itself.
- Needs Chrome or Edge on a desktop. Firefox and Safari don't support WebHID.
- The page carries no list of settings. The connected controller describes its own, so you see
  exactly what your controller and its firmware offer, with help on each one.

## What you can do

**Stick controller**
- See live input, polling rate, missed reports and delay.
- Choose the output mode (DualSense, XInput, DInput) and the stick resolution.
- 8 profiles: switch, name, copy and reset them.
- Calibrate, recentre and fine-tune the sticks, and measure their shape.
- Set each stick's response curve, as points with smoothness or as a Bezier curve with axial lock,
  plus deadzones, overshoot, invert and smoothing.
- Map every button.
- Save your settings to a file and load them back.

**Trackball controller**
- Bind every button to a key or mouse button, with a second set while LT is held.
- Tune the ball, the joystick's movement keys, gyro aim, tilt, lean, the touch pads and spin hold
  on the Trackball tab.

Sliders also move with the mouse wheel.
